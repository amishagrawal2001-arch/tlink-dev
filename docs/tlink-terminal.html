Telemetry

Streaming telemetry, built in

Watch device counters, interface stats, CPU, and memory update live — without leaving your terminal and without setting up Grafana. gNMI streaming plus Prometheus / Telegraf scraping, natively.

gNMI Streaming

Subscribe to sensor paths on Arista, Juniper, Nokia, or any gNMI-compatible target. Bundled gnmic binary handles the RPC; you get the UI.

  • STREAM / ONCE / POLL modes
  • Built-in OpenConfig path catalog
  • Rate view for counter leaves
  • On-disk history retention
  • Save subscriptions per target, auto-restore on relaunch

Prometheus / Telegraf

Point the collector at any /metrics endpoint. Same tabbed UI as the terminal — profiles per endpoint, credentials, TLS, filter expression.

  • Prometheus text-format scrape
  • Telegraf prometheus_client output
  • Bearer token, basic auth, custom TLS trust
  • Mock data source for demos and offline development
  • Metric filter to slice down large exporters

Three views, one data pipeline

Wire log, Latest values, and Graphical charts — toggle between them without losing history. Expand any chart into a full-pane view with wall-clock x-axis and hover crosshair.

  • Wire log with pause / clear / JSONL + CSV export
  • Latest table with sparklines, delta, and freshness dot
  • Graphical card grid: Compact / Normal / Large sizes
  • Auto rate detection on counters (octets, packets, _total)
  • Downloadable self-contained HTML report

Offline AI

An AI assistant that respects your network

Bundled Ollama runtime runs models entirely on your machine. No API keys required. No prompts, code snippets, or command output leaves your laptop unless you choose an external provider.

Local-first, cloud-optional

Start with the bundled local runtime for zero-config privacy. Later, plug in your team's cloud provider — OpenAI, Anthropic, Groq, GLM, MiniMax, vLLM, or any OpenAI-compatible endpoint — without changing the chat UI.

  • Bundled Ollama runtime — models run on your CPU / GPU
  • OpenAI, Anthropic, Groq, GLM, MiniMax, vLLM, Ollama, Tabby — drop-in
  • Per-provider API-key vault — AES-256 at rest
  • Copilot-style agent that can read terminal buffer with permission
  • Redaction: mask secrets before sending anything to a remote provider
  • Per-workspace chat history, exportable to Markdown

Bring your own model runtime

Run vLLM on a beefy dev box, self-host GLM in a private cloud, or use Ollama on the laptop — Tlink Terminal talks to all of them with the same UI, so switching costs are zero.

  • Provider health check: latency, model list, active model
  • Streaming responses with cancellation
  • Context provider: paste last N lines, current file, current profile
  • System prompt editor with team-share presets
  • Local-first mode toggle disables all cloud calls, hard-stop
Workflow

Built for the actual day

The things you do every hour — find the right host, share a session with a teammate, replay something for a ticket, back up your setup — are one click, not a config file.

Session sharing & recording

Hand a live terminal to a teammate for pair-debugging, or record every keystroke to file for tickets and audits. Both ship in the box — no third-party tools, no external service.

  • Multi-user access with per-user read / write scopes
  • Session recording with searchable timeline
  • Downloadable session-as-HTML report for tickets
  • Automatic sudo password from the credential vault

Workspaces & backup

Save your entire layout — open tabs, splits, working directories, active profiles — as a named workspace. Restore in one click, or sync your full setup between laptops with the encrypted backup file.

  • Named workspaces with layout + open tabs + splits
  • Encrypted backup with everything: profiles, keys, themes, AI config
  • Restore on a fresh install in under a minute
  • Community color schemes plugin — hundreds of themes, one click

Plugin manager

Every capability — SSH, RDP, gNMI, collector, AI, api-client — is a plugin. Enable what you need, disable what you don't. Add third-party plugins from the manager UI without touching config files.

  • 25+ built-in plugins, all disable-able
  • One-click install from the plugin browser
  • Update notifications with changelog preview
  • Third-party plugin SDK — publish your own
  • JetBrains bridge for IntelliJ-family editors
