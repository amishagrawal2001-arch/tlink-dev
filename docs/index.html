Features

Everything you need in one terminal

Stop juggling PuTTY, mRemoteNG, WinSCP, and a dozen other tools. Tlink brings it all together.

AI Assistant

Built-in AI powered by OpenAI, Claude, Ollama (local), and more. Get command suggestions, troubleshoot errors, and generate scripts without leaving the terminal.

New

Live Session Sharing

Share terminal sessions with team members via secure links. Read-only for observers or interactive for collaborative troubleshooting. Password-protected with expiration.

New

Session Recording & Replay

Record terminal sessions with timestamps. Replay with speed control (0.5x to 5x) for training, auditing, and debugging. Timestamped JSONL format.

New

Command Palette

Press Ctrl+P to instantly search across open tabs, profiles, recent connections, and commands. Fuzzy search gets you where you need to go fast.

Terminal Bookmarks

Save frequently used commands with labels and categories. Quick-execute from the side panel or command palette. Never retype complex commands again.

Smart Output Analyzer

Auto-detects errors in terminal output (permission denied, command not found, connection refused) and shows fix suggestions in real-time.

Encrypted Vault

AES-256 encrypted credential storage with PBKDF2 key derivation. SSH keys, passwords, and API keys secured with system keyring integration.

Split Panes & Workspaces

Split terminals horizontally and vertically. Save complete workspace layouts and restore them instantly. Drag-and-drop tab management.

SFTP File Browser

Built-in file browser panel for SSH sessions. Upload, download, create directories, and manage remote files without leaving the terminal.

SSH Config Auto-Import

Automatically imports hosts from ~/.ssh/config with live file watching. Changes detected instantly — no restart needed.

Command Window

Send commands to multiple terminals simultaneously. Target active tab, all visible tabs, or every tab at once. Resizable bottom panel.

Plugin System

Extensible architecture with community plugins. Add custom color schemes, AI providers, connection types, and more.

Protocols

One app, every protocol

Connect to any device using the protocol it needs. All in the same window, the same workflow.

SSH

Full SSH2 with password, public key, agent forwarding, jump hosts, SOCKS proxy, and port forwarding (local, remote, dynamic).

  • Key authentication
  • SSH agent
  • Jump hosts / Bastion
  • Port forwarding
  • SOCKS proxy
  • SFTP file transfer

RDP

Windows Remote Desktop with automatic FreeRDP fallback for NLA-enabled servers. Certificate handling and credential management.

  • NLA authentication
  • FreeRDP fallback
  • Certificate handling
  • Session recovery

Serial

Serial console connections for network hardware. Configure baud rate, data bits, parity, and stop bits for Cisco, Juniper, and more.

  • Configurable baud rate
  • Terminal emulation
  • Network device support

Telnet & Socket

Telnet protocol and raw TCP socket connections for legacy devices and custom services.

  • Telnet protocol
  • Raw TCP sockets
  • Legacy device support

Local Shell

Native local terminal with full shell support. PowerShell on Windows, Bash/Zsh on macOS and Linux.

  • PowerShell / CMD
  • Bash / Zsh / Fish
  • WSL support
  • Git Bash / MSYS2

SFTP & ZModem

Integrated file transfer with visual SFTP browser and ZModem protocol support for inline file transfers.

  • Visual file browser
  • Drag-and-drop upload
  • ZModem (sz/rz)
  • Directory operations
