# v2.0.0 — Dashboards

Compose live telemetry from every target you connect to — gNMI devices and
Prometheus / Telegraf endpoints — as tiles on a shared page, with threshold
alerts and shareable JSON exports. This release is the dashboards vehicle.

## What's new

### Dashboards

- **New Dashboards side panel** lists every configured dashboard. Click to open,
  `Add dashboard` to create, `Import` to load from a JSON file.
- **Three tile types** — a big-number *value* tile, a compact *sparkline* tile,
  and a full *chart* tile with area + line and a current-value caption.
- **Mix sources on one page** — a tile can read from any gNMI profile or any
  collector profile in the same dashboard.
- **Drag to reorder** tiles with the row-major 3-column grid. Positions persist.
- **Threshold alerts** on any numeric tile — pick an operator (`>`, `>=`, `<`,
  `<=`, `==`), a value, a severity (info / warning / critical), and whether to
  fire an OS notification. A badge lights the tile while the condition is met;
  the notification is throttled by a per-tile cooldown (default 60 s).
- **Focus-aware notifications** — toast when Tlink has focus, native desktop
  notification when it's in the background.
- **Export and import** — one dashboard per `.tlink-dashboard.json` file.
  Schema is versioned (`tlinkDashboardFormat: 1`) so future format changes
  carry a migration path. Export never includes credentials, keychain refs,
  or user identity — just the dashboard structure.
- **Collision-safe import** — importing a dashboard whose `id` already exists
  lands as `<id>-imported-<suffix>` instead of overwriting.

### Shared telemetry runner

- Under the hood, dashboard tiles and session tabs that watch the same target
  path now share **one** underlying subscription. Opening a dashboard that
  mirrors a live session tab no longer doubles the device load.
- A transient gNMI error on a single subscription no longer terminates every
  observer — error streams are isolated per `(profile, path)`.
- Collector scrape errors now surface as a toast on the session tab. They were
  silent in prior versions.

### Also in this release (v1.2.x cycle)

- **Collector — downloadable HTML session report**, mirroring the gNMI report.
  Self-contained, section-navigable, exports Overview + Source + Latest +
  Graphical in one file.
- **Collector — per-profile starred paths.** Click the star on a Latest row;
  starred paths pin to the top of the view and persist with the profile.
- **SSH key exchange timeout** — a stalled handshake now errors after 30 s
  instead of hanging on `"2/4 Key exchange..."` indefinitely. Configurable
  per profile via `readyTimeout`.
- **Windows CI fix** so Windows builds complete without manual intervention.

## Compatibility

v2.0.0 is **additive**. Existing profiles, saved sessions, recovered tabs,
keychain entries, workspace layouts, and theming all carry over unchanged.
SSH, RDP, serial, terminal, gNMI, and collector flows are unchanged in both
behavior and configuration shape. The version jumps to 2.0.0 because
Dashboards is a substantial new surface area, not because anything breaks.

## Where to start

- Open the **Dashboards** side panel → `Add dashboard` → drop in a value tile
  pointing at any profile you've already connected to once.
- Full user guide: [`docs/dashboards.md`](../dashboards.md).
