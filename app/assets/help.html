Getting Started

Click the + button in the tab bar to open a new connection. Use the Session Manager panel (right sidebar) to browse saved profiles.

Quick-connect: type user@hostname in the command palette (Cmd+Shift+P).

The left dock bar provides quick access to: API Client, Help, and Settings.

SSH

Creating a Connection

Go to Settings → Profiles & connections → + → select SSH. Enter host, port, username, and auth method.

The Test Connection button verifies connection without opening a tab.

Connection Progress

The terminal shows 4-phase progress:

1/4 Connect → 2/4 Key Exchange → 3/4 Auth → 4/4 Ready

Connection Health

• GreenConnected and healthy
• YellowConnected but stale (no recent data)
• RedDisconnected

Auth Methods

Supported: Password, Public Key, SSH Agent, Keyboard Interactive.

Set priority order in profile → Advanced → Authentication Order.

Port Forwarding

Click the plug icon in the SSH toolbar. Supports local, remote, and dynamic (SOCKS5) forwarding.

API Client

Click the globe icon in the left dock bar or tab bar toolbar.

Making Requests

1. Select HTTP method (GET, POST, PUT, DELETE, etc.)

2. Enter the URL

3. Add headers, body, or auth as needed

4. Click Send or press Enter

Response appears on the right with status, timing, formatted JSON, and headers.

Collections

Save requests for reuse: Collections tab → Create collection → click save icon.

Click a saved request to load it back. All fields (URL, headers, body, auth) are preserved.

RDP (Remote Desktop)

Create RDP profiles to connect to Windows machines. NexTerm bundles FreeRDP on macOS — no additional software needed.

If FreeRDP is unavailable, the app prompts to switch to Microsoft Remote Desktop.

Terminal Settings

Color Scheme

Settings → Color scheme — Choose from 190+ built-in themes including Dracula, Nord, One Dark, Catppuccin, GitHub, and more.

Click Edit to customize foreground, background, cursor, and all 16 ANSI colors.

Toggle dark/light mode using the switch in the bottom-right corner.

Button Bar

Settings → Terminal → Button bar — Create custom command buttons above the terminal for quick access to frequent commands.

Output Highlighting

Settings → Terminal → Output keyword highlighting

Automatically colors keywords in terminal output:

UP, OKGreen
DOWN, ERRORRed
WARNINGYellow
IP addresses, interfacesBlue

Add custom rules with regex patterns and any color. Click the color swatch to change.

AI Assistant

Click the robot icon in the SSH toolbar to send selected terminal text to the AI for analysis.

The AI detects common errors (command not found, permission denied) and offers to help via a toast notification.

Configure providers in Settings → AI Assistant. Supports OpenAI, Anthropic, Ollama, and more.

License

NexTerm requires a license. On first launch, click Start Free Trial for 30 days, or enter a license key.

Manage in Settings → License Management.

When the license expires, the app requires activation before use.
