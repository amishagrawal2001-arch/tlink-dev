NexTerm User Guide

Version 1.0.2 — AI-Enhanced Terminal for DevOps & Network Engineers

Getting Started

Opening a Connection

Click the + button in the tab bar, or use the Session Manager panel on the right side.

You can also quick-connect by typing user@hostname in the command palette (Ctrl+Shift+P).

SSH

Connection

Create SSH profiles in Settings → Profiles & connections. Each profile stores host, port, username, auth method, and optional settings.

The connection shows 4-phase progress: 1/4 Connect → 2/4 Key Exchange → 3/4 Auth → 4/4 Ready

Connection Health

The tab dot indicates connection status:

● GreenConnected and healthy
● YellowConnected but no data received (stale)
● RedDisconnected

SFTP

Click the folder icon in the SSH tab toolbar to open the SFTP panel.

Features: file upload/download, drag-and-drop, bookmarked paths, transfer progress, directory creation.

Double-click a file to download it. Star a path to bookmark it for quick navigation.

Port Forwarding

Click the plug icon in the SSH tab toolbar to manage port forwards (local, remote, dynamic SOCKS).

Auth Methods

Supported: Password, Public Key, SSH Agent, Keyboard Interactive. Set priority order in profile settings → Advanced → Authentication Order.

API Client

Click the API icon in the tab bar toolbar to open a new API request tab.

Making Requests

1. Select method (GET, POST, PUT, DELETE, etc.)

2. Enter the URL

3. Add headers, body, or auth as needed

4. Click Send or press Enter

Collections

Save requests to named collections for reuse. Click the Collections tab → create a collection → click the save icon to store the current request.

RDP

Create RDP profiles to connect to Windows Remote Desktop. NexTerm bundles FreeRDP — no additional software needed on macOS.

If FreeRDP fails, the app offers to switch to the system RDP client (Microsoft Remote Desktop).

Terminal Settings

Color Scheme

Settings → Color scheme — Choose from built-in themes or customize all 16 ANSI colors.

Output Highlighting

Settings → Terminal → Output keyword highlighting

Color-codes keywords in terminal output (UP=green, DOWN=red, ERROR=red, etc.). Add custom regex rules with any color.

Button Bar

Settings → Terminal → Button bar — Create custom command buttons displayed above the terminal.

AI Assistant

Click the robot icon in the SSH tab toolbar to send terminal output to the AI assistant for analysis.

The AI also detects common errors (command not found, permission denied, etc.) and offers to help via a toast notification.

Configure AI providers in Settings → AI Assistant.

License

NexTerm requires a license for continued use. On first launch, you'll see the activation dialog.

Options: Enter a license key, or click Start Free Trial for a 30-day trial.

Manage your license in Settings → License Management.
